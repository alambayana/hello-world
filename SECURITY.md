# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | :white_check_mark: |

Only the latest released version of each project receives security fixes.

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub
issues.

Report a suspected vulnerability by emailing the maintainers at
<alambayana@gmail.com>. If private vulnerability reporting is enabled on
this repository, you can instead use **Security → Report a vulnerability**
on the repository page, which keeps the report private until it is
resolved.

You should receive an acknowledgment within **48 hours**, and a substantive
response within **7 days** describing the next steps. Where possible we will
confirm whether we have identified the problem before sending a full reply,
and we will coordinate on a fix and a patched release before any public
disclosure.

## Scope notes for this project

`hello-world` is a local, single-user command-line tool: it has no network
access, no credentials, no authentication, and no stored data. Its realistic
risk surface is small (for example, unusual behaviour on untrusted input),
but any concern is welcome.

All **alambayana** repositories follow the same security-policy shape:
supported versions, a private reporting channel, and a published response
timeline.
